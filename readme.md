# Taller DevSecOps: Seguridad en el Ciclo de Vida del Software

**Diplomatura de Ciberseguridad** | UNS - DCIC

---

## Descripción

Introducción práctica a DevSecOps: integración de controles de seguridad en el pipeline de desarrollo, desde el análisis de código hasta la operación segura de aplicaciones.

---

## Contenido

| Módulo | Temas |
| --- | --- |
| **Fundamentos** | Security by Design, roles DevSecOps, SDLC seguro |
| **Aplicaciones** | OWASP Top 10, SAST/DAST, análisis de dependencias |
| **CI/CD** | Automatización de seguridad, gestión de secretos, firma de código |
| **Infraestructura** | Scanning de contenedores, hardening, logging de seguridad |

---

## Proyecto: shooish-shop

Aplicación ejemplo que demuestra vulnerabilidades comunes y remediaciones:

- Identificar y documentar vulnerabilidades
- Implementar controles de seguridad
- Automatizar pruebas en el pipeline
